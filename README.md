# 🚀 JustChat – Real-Time Chat Application

A scalable real-time chat application that enables seamless one-to-one messaging using WebSockets. Built with a modern full-stack architecture focusing on performance, responsiveness, and secure communication.

---

## 🌐 Live Demo  
[View Project](https://just-chat-hsk2.onrender.com/login)/)

---

## 📌 Features

- 💬 Real-time messaging using Socket.io  
- 🔐 Secure authentication with JWT  
- 🟢 Online / Offline user status tracking  
- 📩 Instant message delivery without page refresh  
- 📱 Responsive user interface  
- ⚡ Fast and scalable backend  

---

## 🛠 Tech Stack

**Frontend**
- React.js  
- Tailwind CSS  

**Backend**
- Node.js  
- Express.js  
- Socket.io  

**Database**
- MongoDB  

---

## 🏗️ System Architecture

Client (React)  
↓  
WebSocket (Socket.io)  
↓  
Node.js Server (Express)  
↓  
MongoDB Database

## ⚙️ Installation & Setup

### 1. Clone the repository
git clone https://github.com/nishant8975/justchat-realtime-app.git

cd justchat-realtime-app


---

### 2. Setup Backend


cd backend
npm install
npm run dev


---

### 3. Setup Frontend


cd frontend
npm install
npm run start


---

## 🔑 Environment Variables

Create a `.env` file in the backend folder and add:
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
